## 2. 理论学习（Theory）

### 2.1 开环 vs 闭环

开环：只发指令不反馈，负载/电压/摩擦变化都会导致转速偏差，无法修正。

闭环：指令 + 反馈 + 修正。编码器测出实际转速 → 与目标比出偏差 → 用偏差修正 PWM → 再测再修。PID 就是"根据偏差计算修正量"的算法。

### 2.2 PID 三要素

* **P（比例）**：偏差越大修正越猛，响应快；纯 P 存在稳态误差
* **I（积分）**：累加历史偏差消除稳态误差；积分过强会超调震荡
* **D（微分）**：观察偏差变化趋势提前刹车，抑制超调；对噪声敏感

位置式离散 PID：

```text
u(k) = Kp·e(k) + Ki·Σe(i) + Kd·[e(k) − e(k−1)]
```

增量式离散 PID（只输出增量）：

```text
Δu(k) = Kp·[e(k)−e(k−1)] + Ki·e(k) + Kd·[e(k) − 2e(k−1) + e(k−2)]
```

实现时直接加**积分限幅/积分分离**（江协 2-1），防止积分饱和失控。

### 2.3 编码器测速

直流减速电机 + 霍尔编码器：电机轴码盘输出 A/B 两路正交方波，相位差 90°，可同时测速与判方向（A 超前 B 为正转）。

F103 **TIM3 编码器模式**（PA6=CH1 接 A、PA7=CH2 接 B）硬件自动计数，最多 4 倍频（A/B 双沿都数）。

```text
转速(RPM) = 每周期计数值 / 每转计数值 × (60 / 周期秒数)
每转计数值 = 码盘线数 × 4 × 减速比
```

杂牌电机齿轮比与码盘线数未知，Day25 必须**实测标定**每转计数值。测速用 M 法（固定时间窗口数脉冲）；铁律：**编码器读取周期 ≤ PID 控制周期**。

### 2.4 PWM 电机驱动

L298N 为 H 桥驱动：PA0（TIM2_CH1）PWM → IN1，PA1 → IN2 方向，ENA 跳帽短接使能，OUT1/OUT2 接电机。

* 占空比 → 平均电压 → 转速；存在启动死区（占空比过低不转）
* PWM 频率避开人耳可听区（1~2kHz 啸叫），常用 10kHz 左右
* 电机电流走 L298N，不经 F103；12V 电源与逻辑电源必须共地

## 7. 工程总结（Engineering Summary）

## 反馈是闭环的灵魂

开环只能"发指令"，闭环才能"保精度"。编码器、PID、PWM 三者构成最小闭环：测 → 算 → 驱动。

## 未知参数必须实测

电机每转计数值不能靠理论值硬算，标定是测速可信的前提；这类"硬件未知数"是嵌入式排障的常见来源。

## 8. 面试问答（Interview Prep）

### Q1：PID 三个参数分别解决什么问题？

答题要点：

* P：快速响应，但纯 P 有稳态误差
* I：积分消稳态误差，过强会超调
* D：微分抑制超调，对噪声敏感

### Q2：位置式与增量式 PID 的区别？

答题要点：

* 位置式输出绝对值，需处理积分限幅
* 增量式只输出增量，抗积分饱和、故障影响小
* 本项目选增量式 + 积分限幅/分离

### Q3：为什么编码器需要 A/B 两路？

答题要点：

* 正交信号同时测速和判方向
* TIM 编码器模式硬件 4 倍频计数

### Q4：PID 调参顺序？

答题要点：

* 先只加 P 到临界震荡，再加 I 消稳态误差，最后微调 D
* 每次只动一个参数
* 用波形工具观察阶跃响应判断超调
