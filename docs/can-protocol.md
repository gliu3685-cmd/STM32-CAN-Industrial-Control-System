# CAN 应用层协议文档

> 总线参数：CAN 2.0B 标准帧（11 位 ID），波特率 **500 kbps**，双端 120Ω 终端电阻。

## 1. 帧 ID 总表

| 帧 ID | 方向 | DLC | 内容 | 周期 |
|---|---|---|---|---|
| 0x100 | F407 → 总线 | 8 | 主控心跳：seq(2B LE) + 0x55AA + 预留 4B | 1s |
| 0x101 | F407 → Node1 | 1 | 命令：data[0]=0x01 请求上报温度 | 按需 |
| 0x102 | Node1 → F407 | 2 | 温度：temp(2B LE，0.1℃ 可自定义) | 1s |
| 0x103 | Node1 → 总线 | 6 | MPU6050 加速度：ax/ay/az 各 2B LE | 1s |
| 0x201 | F407 → Node2 | 3 | 命令：data[0]=0x01，data[1..2]=目标速度(2B LE, 0~1000) | 10s/按需 |
| 0x202 | Node2 → F407 | 2 | 速度：RPM(2B LE)（Day25 起，之前为每秒计数） | 1s |

字节序：多字节字段一律**小端**（低字节在前）。

## 2. 各帧详解

### 0x100 主控心跳

```
data[0..1] = seq（2B LE，每帧 +1）
data[2..3] = 0x55 0xAA（特征字）
data[4..7] = 预留 0
```

用途：宣告主控在线；从节点据此判断主控是否离线。

### 0x101 / 0x102 温度请求与上报

* 0x101：data[0]=0x01 请求 Node1 上报温度
* 0x102：temp(2B LE) 温度数据，Node1 周期 1s 上报

### 0x103 MPU6050 加速度

```
data[0..1] = ax（2B LE）
data[2..3] = ay
data[4..5] = az
```

Node1 周期 1s 广播；主控当前未启用过滤接收（预留姿态控制）。

### 0x201 设置速度命令

```
data[0] = 0x01（命令码：设置速度）
data[1..2] = 目标速度（2B LE，0~1000）
```

速度 0 = 停转（IN1/IN2 双低）；>0 = 正向驱动（占空比上限 800，80%）。Node2 收到后打印 `CMD set-speed=xxx` 并回 0x202。

### 0x202 速度反馈

```
data[0..1] = RPM（2B LE）
```

Node2 每 1s 上报；Day25 标定后语义为 RPM（每转计数 PPR=1079）。

## 3. 心跳与离线检测

* 主控 1s 一帧 0x100；从节点持续收到则判定主控在线
* 连续超时（如 5s）未收到 → 判定离线并告警；恢复后自动清除标志
* 实测（Day19/21）：拔线/断电/拔主控三种故障注入可区分“单节点离线”与“主控 ACK 错误”，30 分钟压力测试错误计数 0

## 4. 验证方法（PCAN-View）

1. 通道选 USB-CAN，波特率 500 kbit/s；
2. 上电后应看到 0x100/0x102/0x202 周期帧；
3. 发送 0x201 `01 F4 01`（速度 500）：Node2 串口打印 `CMD set-speed=500`，0x202 反馈 RPM；
4. 拔 Node2：主控报离线；插回自动恢复。

## 5. 与 IAP 协议的关系

IAP 升级走 **UART**（USART1 115200），不占用 CAN 帧 ID，协议见 [bootloader-plan.md](bootloader-plan.md)（A5 5A 帧 + ERASE/WRITE/FINISH/REBOOT + CRC32）。
